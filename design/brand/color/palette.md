# Persiqa Color

## Primary Brand Color

**Persiqa Amber**

- Variant: **A03 — Rich & Sophisticated**
- HEX: **#C25F05**

This is the canonical Persiqa brand color.

Amber carries meaning rather than acting as decoration. Use it for meaningful emphasis such as active/selected states, important nodes, meaningful connections, key data points, focus elements, and primary actions.

Do not replace this color with another Amber variant unless the visual design system is explicitly revised.

## Neutral Environment

The brand is supported by restrained neutrals: black / near-black, charcoal, graphite, white, warm off-white, and light/medium gray.

Exact neutral tokens remain an implementation task.
