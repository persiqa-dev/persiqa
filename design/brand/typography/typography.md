# Persiqa Typography

## Typeface

**Manrope** is the primary typeface of the Persiqa visual identity.

It provides a modern, geometric, clean, and highly legible typographic foundation that complements the precise and structured character of the Persiqa visual system.

## Primary Weights

| Weight | Use |
|---|---|
| Regular (400) | Body text, descriptions, supporting information |
| Medium (500) | UI labels, secondary headings, navigation |
| SemiBold (600) | Primary headings, prominent labels, wordmark |
| Bold (700) | Strong emphasis and selected display use |

SemiBold (600) is the approved weight for the Persiqa wordmark.

## Wordmark

The approved Persiqa wordmark is based on **Manrope SemiBold (600)**.

The `i` dot is replaced by a Persiqa node derived from the approved v15 logo geometry. The node uses the same geometry and size as the logo node, creating a direct visual connection between the symbol and the wordmark.

The final wordmark is converted to vector paths and therefore does not require the Manrope font at runtime.

## Typography Principles

Persiqa typography should be:

- clean
- precise
- modern
- geometric
- highly legible
- restrained
- structurally consistent

Typography should support the information-dense and knowledge-driven nature of Persiqa without becoming overly decorative or futuristic.

## Hierarchy

Use typographic hierarchy to clearly distinguish:

1. page and section titles
2. headings and subheadings
3. body content
4. metadata and labels
5. technical and data-oriented information

Hierarchy should primarily be established through size, weight, spacing, and layout rather than excessive stylistic variation.

## Technical Content

Manrope may be used for technical UI, diagrams, labels, and data visualization.

Where monospaced typography is semantically required—for example code, source snippets, or terminal output—a suitable monospace typeface may be used. This does not replace Manrope as the primary Persiqa typeface.
