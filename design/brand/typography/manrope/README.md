# Manrope

Manrope is the primary typeface used by Persiqa.

## Usage

The Persiqa visual identity uses Manrope as its primary typeface.

### Wordmark

- Typeface: Manrope
- Weight: SemiBold (600)
- The approved Persiqa wordmark is converted to vector paths.
- The wordmark SVG does not require the Manrope font at runtime.

### Design System

Manrope may be used across the Persiqa visual design system for:

- UI
- headings
- body text
- labels
- data visualization
- documentation and other branded materials

Use the appropriate Manrope weight according to the context.
