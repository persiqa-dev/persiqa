# Persiqa Design System

This directory contains the canonical visual design system of Persiqa.

## IMPORTANT

The Persiqa visual direction is **FIXED**.

Do not restart visual exploration unless explicitly requested.

Canonical decisions:

- Official logo geometry is defined by `brand/logo/geometry-reference.png`.
- The logo geometry MUST NOT be regenerated, simplified, stylized, detached, or otherwise modified.
- P3 break is fixed.
- W4 geometry is fixed.
- The central cube consists of three simple flat faces with even separation.
- Primary brand color: **Persiqa Amber `#C25F05` (A03 — Rich & Sophisticated)**.
- Typography: **Inter**.
- Iconography: minimal geometric, **24×24** base grid.
- Graphic vocabulary: **HEXAGON / CUBE / NODE / CONNECTION / GRID**.
- The visual language is modern, clean, geometric, precise, structured, and knowledge-driven.

See `DESIGN_SYSTEM.md` for the complete specification.

## Directory semantics

- `brand/` — canonical brand definitions and assets.
- `iconography/` — icon system references.
- `graphics/` — graphic-language references.
- `examples/` — approved visual examples; these illustrate the system but do not override the written specification.
- `exploration/` — historical design exploration only. These files are **not** alternative canonical designs.
