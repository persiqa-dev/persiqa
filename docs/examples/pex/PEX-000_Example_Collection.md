**Document:** Persiqa Example Collection (PEX)

**Chapter:** PEX-000

**Title:** Example Collection

**Status:** Accepted

------------------------------------------------------------------------

# Purpose

This collection demonstrates how the Persiqa architecture is applied to
real systems.

Each example follows exactly the same structure to make comparison easy
and to validate that the Core remains universal across domains.

------------------------------------------------------------------------

# Standard Example Structure

Every example SHALL contain:

1.  Real-world scenario
2.  Natural language description
3.  Initial Statements
4.  Refinement
5.  Views
6.  Zoom levels
7.  Final observations

# Success Criteria

Every example SHALL be modelled using only the Persiqa Core:

-   Entity
-   Capability
-   Relation
-   State

Any additional domain knowledge SHALL be expressed through refinement
rather than Core expansion.
