# Persiqa Architecture

This section documents the architectural structure and decisions of Persiqa.

## Architectural Decisions

Architectural decisions are recorded under `docs/architecture/adr/`.

ADRs capture decisions, their context, rationale, consequences, and relevant
alternatives. They do not replace the normative specifications.

## Relationship to Specifications

Architecture documents describe the architectural structure and decisions of
the project.

Normative semantics are defined under `docs/specification/`.

When an architectural decision affects normative behavior, the corresponding
specification documents should be updated as part of the same change.

## Reading Architecture Documentation

Start with the ADRs for recorded architectural decisions, then consult the
relevant specifications for their normative consequences.
